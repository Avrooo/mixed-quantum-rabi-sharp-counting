# mixed-quantum-rabi-sharp-counting

Reproducible symbolic derivations, exact algebraic certification, numerical spectral validation, and figure-generation code for sharp counting bounds in the biased mixed quantum Rabi model.

Companion repository to *Exact polynomial eigenstates and sharp counting bounds in the biased mixed quantum Rabi model* (S. S. Avro). Archive DOI: to be added after the Zenodo release (see `CITATION.cff`).

**Status (v1.0.0).** The theorems are the author's own and unrefereed; computational checks here support them but do not replace the proofs. No independent human audit has been done. See `docs/PROOF_AUDIT_REPORT.md` and `docs/THEOREM_STATUS.csv` for exactly what is and is not verified, including one result (Observation 4) with no archived verification script. The authoritative manuscript is the Word file in `manuscript/`; LaTeX is not needed for anything here.

## Quick start
```
pip install -r requirements.txt      # or: conda env create -f environment.yml
sh reproduce.sh                      # Windows: ./reproduce.ps1  (exits nonzero on any failure; ~5 min)
```
All scripts are pure Python 3 (standard library `fractions`/`decimal` for exact arithmetic; numpy, scipy, matplotlib for numerics and figures). Python 3.13.18 was used. Scripts must be run with `code/` as the working directory (the reproduce scripts do this). Long optional scans: `python3 exc_scan.py`.

## Layout (existing script names are kept; they were not renamed)
| Proposed role | Actual location |
|---|---|
| Hamiltonian, Bargmann transformation, termination recursion | `code/exact.py` |
| Constraint polynomials, rational reconstruction | `code/ratrec.py`, `code/geom.py`, `code/ratfunc.py` |
| Highest-weight forms, projective roots at infinity | `code/topw.py`, `code/gforms.py`, `code/symcheck.py` |
| Limiting system | `code/limit_sys.py`, `code/limitpoly.py` |
| Krawtchouk and spin checks | `code/verify_krawtchouk.py`, `code/verify_prop12.py`, `code/audit_zero_spin.py` |
| Fock diagonalization, Table V | `code/validation_table_run.py`, `code/supp_table5.py` |
| Fig. 8 observables (densities, photon numbers, Wigner) | `code/make_figures3.py` |
| Figures 1-8 | `code/make_workflow.py`, `make_figures.py`, `make_figures2.py`, `make_figures3.py` -> `figures/` (PDF + 900 dpi PNG together) |
| Independent raw-operator check of counting/attainment | `code/audit_independent.py` |
| Log gate (fails the run if a pass marker is missing) | `code/check_logs.py` |
| Tests | `tests/` (Prop. 14 sign logic, Prop. 12 spin identity, eigenstate vs Fock diagonalization, certified root counts) |
| Data | `code/data/` (certified counts, exceptional couplings, `fig8/`) |
| Execution outputs | `code/logs/` (all scripts' logs) |
| Manuscript (Word, authoritative) | `manuscript/` |
| Supplemental Material | `docs/` |

## Fig. 8 data (`code/data/fig8/`)
`fig8_summary.csv` (full-precision parameters, energies, spin weights, mean photon numbers, Wigner minima and negative volumes, overlaps, truncation weights), `fig8_cutoff_convergence.csv`, and `fig8_state_n{1,3,6}.npz` (analytic and Fock-diagonalization coefficients, photon distributions, position densities, Wigner grids). Regenerate with `python3 make_figures3.py` from `code/`.

## Known limitations
- Table V parameters are stored as doubles in the Fig. 8 data; the 40-digit values are in `code/logs/supp_table5.log` and the Supplemental Material.
- Two negative-coupling rows in `CERTIFIED_ROOT_COUNTS.csv` timed out and are not claimed as certified.
- `sh reproduce.sh` takes several minutes; `exc_scan.py` much longer.

## Verified in a clean environment
A fresh copy was run with `env -i` (empty environment, no pre-generated logs, figures or tables) using system Python 3.13 with numpy 2.5.3, scipy 1.18.1, matplotlib 3.11.2, pytest 9.1.1. Installing packages from PyPI into a new virtual environment could not be tested because the build sandbox has no network access. Failure propagation was tested by injecting a failing script (exit 1) and a missing log (log gate exit 1).
